# 无人机运行领域约定

服务面向低空运行、机队运维和合规管理人员。时间字段统一使用带时区的 ISO 8601 字符串，位置、授权和设备事件应保留来源时间与接收时间，不能用展示层文字替代结构化状态。

健康接口只表示进程存活，不代表任何飞行或审批业务已经完成。需要落盘的数据应使用运行时配置指定的位置，测试不得依赖主机上的隐藏状态。

## 远程识别登记与异常核查

本服务把设备注册、操作员、飞行授权、广播序列和接收站观测组织成可追溯关联：

- **身份连续性**：广播身份（remote_id）通过证书链绑定到设备；证书轮换以
  `replaces_cert_id` 链接旧证书，轮换期间设备身份保持连续。
- **轨迹可信度**：轨迹只按机载时间排序、按内容去重重建，与报文到达顺序无关；
  同一机载时刻同一序号但位置矛盾的观测会被拆分而不是合并。接收站时钟漂移
  只降低证据置信度（confidence 与 limiting_factors），不直接形成定性。
- **异常检测**：重复身份、不可达速度、位置跳变、过期证书四类规则命中后
  一律建立人工复核案件，系统不作最终定性。每条证据记录采用的规则版本与参数。
- **案件处置**：合并、排除、升级、分诊、结案均以追加事件完成，历史不可改写；
  复核时限（review_due_at）随案件落盘，服务重启后未结案件照常推进。
- **隐私**：操作员的电话、邮箱、证件号仅调查员（investigator）角色可见，
  其他角色检索时得到脱敏视图。
