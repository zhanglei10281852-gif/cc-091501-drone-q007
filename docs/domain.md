# 无人机运行领域约定

服务面向低空运行、机队运维和合规管理人员。时间字段统一使用带时区的 ISO 8601 字符串，位置、授权和设备事件应保留来源时间与接收时间，不能用展示层文字替代结构化状态。

健康接口只表示进程存活，不代表任何飞行或审批业务已经完成。需要落盘的数据应使用运行时配置指定的位置，测试不得依赖主机上的隐藏状态。

## 远程识别与异常核查约定

- 广播报文以 `(remote_id, message_id)` 去重，接收站观测以 `(报文, 接收站)` 去重；航迹一律按广播源时间排序后构建，乱序或重复报文不得拼出虚假轨迹。
- 证书可多张并存（轮换），任一证书覆盖广播时间即视为身份连续；只有全部证书都未覆盖时才形成过期证书发现。
- 接收站时钟漂移只下调证据可信度，不直接形成定性；所有异常结论都必须经人工复核案件落地。
- 案件的合并、排除、升级、办结等处置一律通过追加证据事件完成，事件流不可篡改，状态只是其投影；复核时限以绝对时间落库，服务重启后照常推进。
- 操作员的个人联系方式属于受控字段，仅调查员角色可见，其余角色一律脱敏。
